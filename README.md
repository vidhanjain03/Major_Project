# 🛡️ Real-Time Face Mask & Intrusion Detection

This project implements a real-time face mask detection and intrusion detection system using computer vision techniques.  
It leverages deep learning models to identify whether individuals are wearing masks and to detect unauthorized intrusions.

---

## 📂 Project Structure


- `face_detector/`
- `mask_detector.model`
- `thiefdetection.ipynb`
- `videomaskdetection.ipynb`
- `Covered-Face-dataset.zip`


## 🚀 Getting Started

### Prerequisites

- Python 3.x
- Jupyter Notebook
- OpenCV
- TensorFlow or Keras
- NumPy

## 📊 Usage

### Face Mask Detection
Run the ```videomaskdetection.ipynb``` notebook to perform real-time face mask detection using your webcam.

### Intrusion Detection
Run the ```thiefdetection.ipynb``` notebook to detect unauthorized intrusions from a video feed.

## Dataset
The ```Covered-Face-dataset.zip``` contains the dataset used for training the mask detection model.
Extract it before training or evaluation.
